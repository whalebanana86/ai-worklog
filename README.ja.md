**「AIと一緒に、こんなことまでやっていたの？」**

これ、私が？は、**Claude Code・Codex・LM Studio**と一緒に行った作業を、日付とプロジェクト別にまとめるMacアプリです。
依頼、回答、変更したファイル、AIの要約を振り返り、自分が成し遂げたことを再発見できます。

[最新版をダウンロード](https://github.com/whalebanana86/ai-worklog/releases/latest)

## できること

- 日付別・プロジェクト別に作業を振り返る
- AIへの依頼と回答を検索する
- 作業時間、依頼数、変更したファイルを確認する
- ログをMac内の保管庫に保存し、読み取り済みの記録を原本の削除後も残す
- インストール済みのAIツールで、その日の作業を要約する
- 日別・期間別のレポートをMarkdownで書き出す
- プロジェクトで使うスキル、ルール、設定を確認する

## インストール

macOS 14以降に対応。リリース版はAppleシリコン・Intelの両方で動作します。

1. [Releases](https://github.com/whalebanana86/ai-worklog/releases/latest)から `Igeolnaega-<バージョン>-macOS.dmg` をダウンロードします。
2. DMGを開き、アプリを **Applications（アプリケーション）** にドラッグします。
3. アプリケーションから **これ、私が？** を開きます。
4. 未公証のビルドで警告が表示された場合は、信頼する配布元であることを確認し、**システム設定 → プライバシーとセキュリティ → このまま開く** を選択します。

ファイル名はすべての言語で `이걸내가.app` です。Finderやアプリのメニューには日本語名が表示されます。
以前のリリースは `AI-Worklog-…` というファイル名です。
以前の名前 **AI作業日誌 / AI 작업일지** のアプリがある場合は、新しいアプリをコピーした後、古いアプリをゴミ箱に移動してください。
保存済みの記録と設定は引き継がれます。

### ソースからビルド

XcodeまたはCommand Line Toolsが必要です。

```bash
git clone https://github.com/whalebanana86/ai-worklog.git
cd ai-worklog
scripts/build_app.sh --install --no-summary
```

既存のアプリが `/Applications` にあればその場所を更新し、なければ `~/Applications` にインストールします。
`--no-summary` を外すと、過去の日付のAI要約も作成します。AIツールへのログインが必要な場合があります。

## 言語とアップデート

**これ、私が？ → 設定…** で日本語・英語・韓国語を選べます。
画面の文言はすぐに切り替わり、macOS標準メニューは再起動後に切り替わります。

**これ、私が？ → アップデートを確認…** でGitHubの最新の正式リリースを確認します。
新しいバージョンがある場合は **インストールして再起動** を選びます。ZIPをダウンロードし、GitHubのSHA-256、アプリの署名・識別情報・バージョン・対応環境を検証してから、アプリを置き換えて再起動します。
記録と設定は保持されます。置き換えや再起動の要求に失敗した場合は以前のアプリに復元し、成功時は以前のアプリをゴミ箱へ移動します。
記録の読み込み、AI要約、レポート編集が終わってから更新してください。書き込み権限がない場合や検証できるZIPがない場合は、ダウンロードページから手動でインストールできます。
起動時にも更新を確認しますが、インストールボタンを押すまではダウンロードや置き換えを行いません。この機能がない旧バージョンからは、一度手動で更新してください。

## 記録とAI要約

記録はMac内の `~/Library/Application Support/AIWorkLog` に保存されます。
アプリに読み取られる前に削除された原本は復元できません。

AI要約を利用する場合、その日の依頼・回答・変更したファイル名が選択したAIに送られます。
Claude CodeはAnthropic、CodexはOpenAI、LM Studioは設定したローカルサーバーを使用します。
設定でAI要約を無効にしても、記録の閲覧は利用できます。

詳しい仕様・開発手順は [English README](README.en.md) と [한국어 README](README.md) を参照してください。

## プロジェクトの非表示

サイドバーのプロジェクトを右クリックして **サイドバーで非表示** を選択します。設定は次回の起動後も保持されます。
一覧の下の **非表示のプロジェクト（N件）** から個別に再表示するか、**すべてのプロジェクトを再表示** を選べます。
記録・検索結果・統計は保持されます。選択中のプロジェクトを非表示にすると概要画面に戻ります。
