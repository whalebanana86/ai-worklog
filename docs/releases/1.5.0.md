## v1.5.0 변경 사항 / What's new / 変更点

- 왼쪽 패널에서 프로젝트를 우클릭해 **왼쪽 목록에서 숨기기**를 선택할 수 있어요.
- 목록 아래 **숨긴 프로젝트 N개**에서 프로젝트를 개별 복원하거나 **모든 프로젝트 다시 표시**를 선택할 수 있어요.
- 숨김 상태는 앱을 다시 열어도 유지돼요. 경로별로 저장해 이름이 같은 프로젝트도 따로 관리해요.
- 숨긴 프로젝트의 기록·검색 결과·통계는 그대로 유지돼요. 현재 선택한 프로젝트를 숨기면 한눈에 보기로 돌아가요.
- 한국어·영어·일본어를 지원해요.

**English:** Right-click a project to **Hide from Sidebar**. Restore individual projects or all projects from **Hidden Projects (N)** below the list. Hidden state persists across restarts and is stored by project path. Records, search results and statistics are preserved. Hiding the selected project returns to Overview.

**日本語:** プロジェクトを右クリックして **サイドバーで非表示** を選べます。一覧の下の **非表示のプロジェクト（N件）** から個別またはすべてのプロジェクトを再表示できます。設定はパスごとに保存され、次回の起動後も保持されます。記録・検索結果・統計は保持されます。選択中のプロジェクトを非表示にすると概要画面に戻ります。
