## v1.7.0 변경 사항 / What's new / 変更点

- **작업 시간에 AI 가 일한 시간까지 들어가요.** 지금까지는 내가 요청을 보낸 시각만 보고 재서, 요청 하나에 AI 가 30분 일해도 1분으로 셌어요. 이제 Claude Code 가 응답마다 남기는 걸린 시간("Churned for …")과 Codex 의 작업 기록을 함께 봐요.
- 응답 시간이 실제보다 길게 남은 경우(응답 여러 개를 한데 묶거나 자리를 비운 시간까지 들어간 경우)는 기록이 이어진 곳만 세요. 답을 읽고 10분 안에 다시 물은 시간은 넣고, 10분 넘게 쉰 시간은 빼요.
- 한눈에 보기·날짜별 기록·프로젝트·세션 화면이 모두 같은 방법으로 세서, 프로젝트 화면 머리와 정보 패널의 작업 시간이 맞아요.
- 원본 기록이 지워진 옛 세션과 LM Studio 대화는 응답 시간이 남아 있지 않아 지금처럼 요청 시각으로 재요. 업데이트 뒤 처음 켤 때 Claude Code 기록을 처음부터 다시 읽어서 조금 오래 걸려요.

v1.6.0 이후 버전을 쓰고 있으면 앱 안의 **설치하고 다시 시작**으로 바로 바꿀 수 있어요.

**English:** Work time now includes the time AI spent working. Until now it only looked at when you sent requests, so a request that kept the AI busy for 30 minutes counted as one minute. It now uses the response time Claude Code records for each reply ("Churned for …") and Codex's work log, counting only the stretches the log shows as active: response times that run too long are trimmed, a follow-up within 10 minutes counts, and breaks over 10 minutes don't. Every screen counts the same way, so the project header and the inspector agree. Older sessions whose transcripts were deleted and LM Studio chats keep the request-based time. The first launch after updating re-reads Claude Code logs and takes a little longer. On v1.6.0 or later you can update from the app with **Install and Restart**.

**日本語:** 作業時間に AI が作業した時間も含めるようになりました。これまではリクエストを送った時刻だけで測っていたため、AI が 30 分作業しても 1 分と数えていました。これからは Claude Code が応答ごとに記録する所要時間（"Churned for …"）と Codex の作業記録を使い、記録が続いている部分だけを数えます。長すぎる所要時間は切り詰め、10 分以内に続けて質問した時間は含め、10 分以上の休憩は除きます。すべての画面が同じ方法で数えるので、プロジェクト画面の見出しとインスペクタの作業時間が一致します。元の記録が削除された古いセッションと LM Studio の会話は、これまでどおりリクエスト時刻で測ります。更新後の最初の起動では Claude Code の記録を読み直すため、少し時間がかかります。v1.6.0 以降をお使いなら、アプリの **インストールして再起動** から更新できます。
