## v1.6.0 변경 사항 / What's new / 変更点

- **업데이트 확인 → 설치하고 다시 시작**으로 파일 다운로드, 검증, 앱 교체와 재시작을 앱 안에서 진행할 수 있어요.
- 다운로드 진행률과 설치 단계를 표시하고, 파일의 SHA-256·앱 서명·식별 정보·버전·실행 환경을 검증해요.
- 앱이 종료된 뒤 별도 설치 프로세스가 같은 위치의 앱을 교체해요. 교체나 재시작 요청이 실패하면 이전 앱으로 복구해요.
- 기존 기록·설정과 자동 보관 경로를 유지해요. 기록 읽기·AI 요약·보고서 편집 중에는 작업을 마친 뒤 업데이트하도록 안내해요.
- 쓰기 권한이 없거나 검증 가능한 ZIP이 없는 경우 다운로드 페이지에서 직접 설치할 수 있어요.

**중요:** v1.5.0 이하에는 앱 교체 기능이 없어요. **이번 v1.6.0은 DMG로 한 번 직접 설치해 주세요.** 그다음 새 버전부터 앱 안의 **설치하고 다시 시작**을 사용할 수 있어요.

**English:** Updates can now be downloaded, verified, installed and restarted from the app using **Install and Restart**. SHA-256, code signature, app identity, version and compatibility are checked before replacement. Failed replacement or restart requests roll back to the previous app. Records and preferences are preserved. Read-only locations and releases without a verified ZIP offer manual installation.

**One manual upgrade is required:** v1.5.0 and earlier only open a download page. Install v1.6.0 from the DMG once to enable in-app installation of future releases.

**日本語:** **インストールして再起動** から、ダウンロード・検証・アプリの置き換え・再起動を行えるようになりました。SHA-256、署名、識別情報、バージョン、対応環境を検証します。置き換えや再起動要求に失敗した場合は以前のアプリに復元します。記録と設定は保持されます。

**初回は手動更新が必要です。** v1.5.0以前にはインストール機能がないため、今回のv1.6.0はDMGで一度手動インストールしてください。それ以降の更新はアプリ内から行えます。
