## v1.7.1 변경 사항 / What's new / 変更点

- **원본 기록이 지워진 옛 세션의 작업 시간이 돌아와요.** 1.7.0 에서 이런 세션은 요청 시각으로만 재서 예전보다 짧게 나왔어요. 이제 보관함에 남아 있던 작업 시간을 날짜별로 나눠 다시 써서, 지난 기간과 비교할 때도 줄어 보이지 않아요.
- **LM Studio 대화가 모두 1분으로 나오던 것을 고쳤어요.** 대화를 만든 때부터 마지막으로 주고받은 때까지 다시 재요.
- 기간 보고서에서 며칠에 걸친 세션의 AI 가 일한 시간이 하루치만 들어가던 것을 고쳤어요.
- 프로젝트 화면 머리에, 요청 없이 돈 세션만 있는 기간에도 "맡긴 일이 없어요" 대신 세션 수와 작업 시간을 보여 줘요.
- 업데이트 설치를 더 단단하게 했어요. 설치 도우미가 바로 실패하면 앱을 끄지 않고 이유를 보여 주고, 되돌릴 때는 원래 앱을 반드시 제자리로 돌려놓아요. 업데이트 도중 앱이 꺼져 남은 숨김 사본은 앱을 켤 때 치워요. 검증하는 동안 100% 막대가 남던 것도 고쳤어요.
- 보관함의 AI 가 일한 구간을 다른 시각 칸처럼 1970년 기준 초로 저장해요 (다른 도구로 읽을 때 맞도록). 처음 켤 때 한 번 바꿔 둬요.

**1.6.0~1.7.0 에서 업데이트할 때:** 이 버전들은 업데이트 창이 떠 있는 채로 앱을 끄려다 macOS 에 막혀서, **설치하고 다시 시작**을 누르면 "앱을 교체하고 다시 시작하는 중…"에서 멈출 수 있어요. 그러면 1분 안에 이걸내가를 **강제 종료**(⌥⌘⎋)해 주세요. 설치 도우미가 이어서 새 버전으로 바꾸고 다시 열어 줘요. 1분이 지났으면 강제 종료한 뒤 앱을 다시 켜서 같은 방법으로 한 번 더 하거나, 아래 DMG 로 설치해 주세요. 1.7.1 부터는 고쳐져서 다음 업데이트는 멈추지 않아요.

**English:** Older sessions whose transcripts were deleted get their work time back: 1.7.0 counted them by request time only, so they looked shorter than before. The time saved in the archive is now split across their days again, so comparisons with earlier periods no longer look inflated. LM Studio chats no longer all show one minute; they count from when the chat was created until the last exchange. Period reports now include AI working time from every day of a multi-day session. The project header shows sessions and work time for periods that only have sessions without requests. Updates are sturdier: if the installer helper fails right away, the app stays open and shows why; a rollback always puts the original app back; hidden copies left by an interrupted update are removed at launch; and the 100% bar no longer lingers during verification. AI working stretches are stored in Unix seconds like the other time columns, converted once on first launch.

**Updating from 1.6.0–1.7.0:** these versions try to quit while the update sheet is still open, which macOS refuses, so **Install and Restart** can stop at "Replacing the app and restarting…". If that happens, force quit I Did That? (⌥⌘⎋) within a minute; the installer helper then swaps in the new version and reopens it. If more than a minute has passed, force quit, open the app and try the same way again, or install from the DMG below. This is fixed from 1.7.1, so later updates won't stall.

**日本語:** 元の記録が削除された古いセッションの作業時間が戻ります。1.7.0 ではリクエスト時刻だけで測っていたため、以前より短く表示されていました。保管庫に残っていた作業時間を日ごとに分けて使い直すので、過去の期間との比較でも減って見えません。LM Studio の会話がすべて 1 分と表示される問題を直し、会話を作成してから最後にやり取りした時までを測ります。期間レポートで複数日にまたがるセッションの AI 作業時間が 1 日分しか入らない問題を直しました。リクエストのないセッションだけがある期間でも、プロジェクト画面の見出しにセッション数と作業時間を表示します。アップデートのインストールをより堅牢にしました。インストール補助がすぐ失敗した場合はアプリを終了せず理由を表示し、ロールバックでは必ず元のアプリを元の場所に戻します。アップデート中にアプリが終了して残った隠しコピーは起動時に片付けます。検証中に 100% のバーが残る問題も直しました。保管庫の AI 作業区間は他の時刻の列と同じく 1970 年基準の秒で保存し、最初の起動時に一度だけ変換します。

**1.6.0〜1.7.0 から更新する場合:** これらのバージョンはアップデート画面を開いたままアプリを終了しようとして macOS に拒否されるため、**インストールして再起動** を押すと「アプリを置き換えて再起動中…」で止まることがあります。その場合は 1 分以内に「これ、私が？」を **強制終了**（⌥⌘⎋）してください。インストール補助が続けて新しいバージョンに置き換え、もう一度開きます。1 分を過ぎた場合は強制終了してからアプリを開き、同じ方法でもう一度試すか、下の DMG からインストールしてください。1.7.1 からは修正済みなので、次回以降のアップデートは止まりません。
