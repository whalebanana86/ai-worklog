## v1.4.0 변경 사항 / What's new / 変更点

- **이걸내가 — AI와 함께한 일**로 이름과 아이콘을 새롭게 바꿨어요. 기존 기록과 설정은 그대로 이어집니다.
- 영어 **I Did That?**, 일본어 **これ、私が？** 이름과 소개 문구를 적용하고 일본어 README를 추가했어요.
- 앱 메뉴에 업데이트 확인을 추가했어요. 새 버전이 있으면 릴리스 페이지에서 다운로드할 수 있어요.
- 설정 창이 화면보다 길어지던 문제를 고쳤어요. 창 높이를 제한하고 내용을 스크롤할 수 있게 했어요.
- 로컬 빌드의 버전 표시와 설치 경로를 바로잡고, 이름 변경 시 기존 설치와 자동 보관 경로를 이어 주도록 했어요.

**English:** New name and icon, localized branding in Korean, English and Japanese, an app-menu update checker, and a scrollable Settings window that fits laptop screens. Existing records and preferences are preserved. Local installs now report the source version and migrate the previous app name.

**日本語:** アプリ名とアイコンを刷新し、韓国語・英語・日本語の名前と説明を整えました。アプリメニューからアップデートを確認できます。設定画面はノートパソコンの画面内に収まり、内容をスクロールできます。保存済みの記録と設定は引き継がれます。

**이전 버전에서 DMG로 업데이트할 때:** 새 앱을 응용 프로그램 폴더에 복사한 뒤, 예전 이름의 **AI 작업일지 / AI Worklog / AI作業日誌** 앱을 휴지통으로 옮겨 주세요. / **Upgrading from the old name:** copy the new app into Applications, then move the old app to the Trash. / **旧名から更新する場合:** 新しいアプリをアプリケーションにコピーした後、古いアプリをゴミ箱に移動してください。
